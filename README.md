# TOOLVIA

Find the right tool, free. Foundation (v2, rebuilt). Phases 1-2 approved.

## What works in code (not yet run or tested)
Homepage, dark/light mode, working search, category filter, FREE / FREE PLAN / PAID filter, sort,
18 categories, sample-data listings (clearly labeled), robots.txt, sitemap.xml, ad slot (off by default).

## Not built yet
Tool pages, category pages, tutorials, database connection, admin, legal pages, real tool data.

## Run locally (needs Node.js 20+)
    npm install
    npm run dev
Open http://localhost:3000. `npm install` creates package-lock.json; commit it.

## Deploy
Import the GitHub repo into Vercel (free). Add env vars from .env.example.
